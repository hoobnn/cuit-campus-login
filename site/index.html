CUIT 校园网

成都信息工程大学校园网自动登录：macOS 与 Windows 原生应用，连上校园网自动完成认证，掉线自动重连。免费开源（MIT）。

下载 macOS / Windows 版 源代码
brew install --cask hoobnn/tap/cuitnet

常见问题

成都信息工程大学校园网怎么实现自动登录？

安装 CUITNet，填一次学号、密码并选运营商（移动 / 电信 / 联通）。之后它在后台检测网络，被门户拦截就自动重新登录，换网络或从睡眠唤醒时立即检测。

需要装浏览器或 Selenium 吗？

不需要。应用直接按门户协议发 HTTP 请求，没有浏览器、驱动或 Python 依赖。

支持哪些系统？

macOS 14 及以上（Apple 芯片和 Intel），Windows 10 1809 及以上（x64）。Linux 和手机暂不支持。

密码存在哪里？

macOS 存在系统钥匙串，Windows 存在凭据管理器，不写入明文配置文件。

真的能用吗？

协议按社区对真实门户的逆向结果实现，并用本地假门户做了端到端测试；但作者不在校园网内，尚未在真实门户上实测。遇到问题请到 GitHub 提 issue 并附日志。

免费吗？能用于其他学校吗？

免费，MIT 许可。协议实现针对成都信息工程大学的门户（锐捷 SAM 5.x + CAS），其他学校不保证可用。
